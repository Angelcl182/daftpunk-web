# Daft Punk — web retrofuturista

Proyecto educativo creado con Vite (plantilla Vanilla) y Bootstrap 5.3.

## Requisitos
- Node.js LTS y npm

## Instalar y ejecutar
```bash
npm install
npm run dev
```

## Compilar para producción
```bash
npm run build
npm run preview
```

La compilación genera `dist/`. Las fotografías se cargan desde URLs externas; por tanto, es necesaria conexión a Internet para verlas. El formulario es demostrativo y no envía datos.

## Estructura
- `index.html`: estructura y componentes Bootstrap.
- `src/main.js`: imports de Bootstrap CSS, Bootstrap Bundle JS y CSS propio, en el orden solicitado.
- `src/style.css`: personalización retrofuturista y variables Bootstrap.
